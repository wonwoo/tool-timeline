# tool-timeline

[English](README.md) | 한국어

**Claude Code가 턴마다 시간을 어디에 썼는지 보여 줍니다.**

Claude가 답하는 데 1분이 걸렸다면 생각하느라 오래 걸린 걸까요, `npm test`를 기다리느라 오래 걸린 걸까요?
tool-timeline은 도구를 쓴 턴마다 아래에 한 줄을 붙여서 도구를 몇 번 불렀고 무엇이 가장 느렸는지 보여 줍니다. 이 줄을
누르면 턴이 타임라인으로 펼쳐집니다. Claude의 모델 요청과 도구마다 시간 막대가 한 줄씩 나오고, 그 아래에
호출마다 걸린 시간이 나옵니다.

<img src="docs/images/demo.gif" width="880" alt="npm test와 빌드를 돌리는 턴: 스피너 게이지가 빌드의 평소 시간 21초를 향해 차오르고, 턴이 끝나면 접힌 줄을 펼쳐 시간 막대와 호출을 보고, 가장 느린 호출을 누르면 Claude가 왜 오래 걸렸는지 답합니다">

<sub>예시 프로젝트에서 찍은 실제 화면입니다. 터미널 화면은 cmux에서 띄운 Ghostty, 마지막 그림은 데스크톱 앱입니다.</sub>

## 보이는 것

### 도구를 쓴 턴 아래에 붙는 한 줄

Claude Code는 턴이 끝나면 `✻ Cooked for 52s` 같은 줄을 남깁니다. 그 아래에 흐린 글씨로 한 줄이 붙습니다.
도구 호출 수와 가장 느린 호출이 나오고, 호출마다 작은 막대가 실행 순서대로 붙습니다. 막대는 24개까지
그립니다. 호출이 그보다 많으면 막대 하나가 여러 호출을 묶고 그중 가장 느린 시간을 그립니다. 줄을 누르면
펼쳐지고 다시 누르면 접힙니다.

<img src="docs/images/folded.png" width="650" alt="접힌 턴: 6 tool calls · slowest Bash 17.1s와 호출마다 작은 막대">

<img src="docs/images/unfolded.png" width="869" alt="펼친 턴: Claude, Bash, Edit의 시간 막대가 턴 전체 길이에 걸쳐 나오고, 그 아래에 호출마다 걸린 시간이 나옵니다. 가장 느린 호출은 17.1초 걸린 테스트 실행입니다">

펼치면 위에 시간 막대가 나옵니다. Claude의 모델 요청에 한 줄, 도구마다 한 줄씩이고, 줄 끝에 그 도구가 쓴
시간을 적습니다. Claude 줄에는 응답으로 쓴 토큰 수도 붙습니다. 프롬프트의 절반도 캐시에서 읽지 못한 요청은
보라색으로 칠합니다. 캐시를 놓친 요청은 느리고 비용도 더 듭니다. 서브에이전트가 부른 도구는 `↳ Bash`처럼
따로 줄을 받습니다.

그 아래에는 가장 느린 호출 10개가 느린 순서대로 나옵니다. Bash 호출은 명령어 대신 Claude가 붙인 설명을
보여 줍니다. 같은 대상에 반복한 호출은 `Bash ×3`처럼 한 줄로 묶습니다. 실패한 호출에는 `✗`, 규칙이나
권한 확인 창, auto 모드의 분류기가 거부한 호출에는 `⊘`를 붙입니다.

평소 시간의 두 배 이상 걸렸고 평소보다 1초 이상 더 걸린 호출에는 `usual 8.2s`처럼 평소 시간을 적습니다. 평소 시간은 이 프로젝트에서
그 명령을 최근 20번 실행한 시간의 중간값이고, 세션이 바뀌어도 남습니다. 기록이 3번 쌓이면 보이기 시작합니다.
권한을 물어본 호출은 승인을 기다린 시간도 호출 시간에 들어가고, 평소 시간에도 그대로 쌓입니다.

### Claude가 일하는 동안

스피너에 지금 가장 오래 돌고 있는 호출이 나오고, 그 시간이 1초마다 늘어납니다. 그 명령의 평소 시간을 알면
게이지가 평소 시간을 향해 차오릅니다. 평소보다 훨씬 오래 걸리면 `2.3× usual`처럼 몇 배인지 적습니다.

<img src="docs/images/spinner.png" width="779" alt="빌드 중인 스피너: Bash 10s, 반쯤 찬 게이지, usual 21s · 1 tool call">

### 느린 호출의 이유 묻기

터미널에서 5초 이상 걸렸거나 평소보다 훨씬 오래 걸린 호출을 누르면 Claude가 왜 오래 걸렸는지 답합니다.
근거는 그 호출이 실행한 명령과 출력의 끝부분이고, 둘 다 호출이 끝날 때 저장해 둡니다. 근거만으로 시간을
어디에 썼는지 알 수 없으면 그렇다고 말하고, 짐작한 부분은 짐작이라고 밝힙니다. 답은 그 행 아래에 붙고,
다시 누르면 숨겨집니다.

<img src="docs/images/why.png" width="880" alt="가장 느린 행 아래에 붙은 Claude의 답: 17.1초 중 대부분이 전체 테스트였고 그중 e2e 테스트가 11.4초였으니, 실패한 파일만 돌렸으면 충분했다는 내용">

### 세션 전체를 보는 패널

`/tool-timeline`을 입력하면 패널이 열립니다. 위에는 진행 중인 턴이 실시간으로 그려지고, 아래에는 이 세션의
최근 턴 10개가 한 줄씩 나옵니다. 줄마다 걸린 시간, 몇 분 전에 끝났는지, 호출 수, 가장 느린 호출, 입력한
프롬프트의 앞부분이 나옵니다. 줄을 누르면 그 자리에서 펼쳐집니다. 진행 중인 턴은 최근 호출 10개를, 이전
턴은 가장 느린 호출 10개를 보여 주고 나머지는 개수만 한 줄로 적습니다.

<img src="docs/images/pane.png" width="880" alt="패널: 지금 턴의 시간 막대와 호출, 평소 20초 걸리는 빌드가 14.1초째 도는 중, 그 아래 이전 턴 한 줄">

### 데스크톱 앱에서

데스크톱 앱에는 턴을 닫는 줄이 없어서 Claude의 마지막 답 아래에 붙습니다. 앱이 도구 실행을 접어 보여 주는
줄과 같은 흐린 색과 화살표로 그려서 답이 먼저 눈에 들어옵니다.

<img src="docs/images/desktop.png" width="824" alt="데스크톱 앱에서 Claude의 답 아래에 붙은 줄을 펼친 모습: 둥근 시간 막대와 흐린 호출 목록">

### 그 밖에

- 30초 이상 걸린 호출이 끝나면 터미널 알림을 띄웁니다. 데스크톱 앱에는 알림 창구가 없어서, 직접 설정한
  `Notification` 훅만 이 알림을 받습니다.
- 같은 Bash 명령이 중간에 한 번도 성공하지 못하고 3번 연속 실패하면 `Bash failed 3 times in a row · npm test`
  처럼 토스트와 알림을 띄웁니다. Claude가 같은 시도를 되풀이하고 있을 가능성이 높으니 끼어들기 좋은
  때입니다.
- 프롬프트를 보낼 때 이 프로젝트에서 10초 이상 걸리는 명령의 평소 시간을 Claude에게 함께 보냅니다. 화면에는
  보이지 않습니다. 그래서 Claude가 범위를 좁힌 명령을 고르거나 오래 걸리는 명령을 백그라운드로 돌릴 수
  있습니다.
- 세션을 다시 열어도 이전 턴의 접힌 줄이 그대로 남습니다.

## 설치

Claude Code 2.1.295 이상이 필요합니다. 터미널 세션의 입력창에 이렇게 입력하세요.

```
/plugin install tool-timeline --marketplace wonwoo/tool-timeline
```

마켓플레이스를 추가할지 물으면 `y`를 누르고 설치 범위를 고르면 됩니다. 맨 위가 user 범위입니다. 설치한
세션에서 바로 동작하고, 그 뒤에 여는 세션에도 적용됩니다. 데스크톱 앱의 Code 탭에서는 이 명령을 쓸 수
없지만, 터미널에서 user 범위로 설치하면 데스크톱 앱에서도 동작합니다. Ghostty와 kitty에서는 막대를 이 문서의
화면처럼 그림으로 그리고, 다른 터미널에서는 같은 막대를 글자로 그립니다.

## 비용과 저장하는 것

모델에 보내는 건 두 가지뿐이고 나머지는 모두 로컬에서 그립니다. 하나는 이유 묻기입니다. 세션의 대화 기록을
바탕으로 모델 요청을 한 번 보내고, 프롬프트 캐시가 살아 있으면 캐시에서 읽습니다. 이 질문과 답은 대화에
남지 않습니다. 다른 하나는 평소 시간 안내입니다. 프롬프트와 함께 몇 줄을 보내는데, 세션의 첫 프롬프트에
한 번 보내고 그 뒤로는 평소 시간이 바뀌었거나 대화가 압축됐을 때만 다시 보냅니다.

Claude Code의 플러그인 저장소에는 두 가지를 저장합니다. 하나는 프로젝트마다 명령과 도구별로 최근 20번의
실행 시간입니다. 모두 합쳐 1,000가지까지 남기고, 넘치면 가장 오래 안 쓴 것부터 지웁니다. 다른 하나는 최근
세션 5개의 끝난 턴입니다. 턴 안에서 1초 이상 걸린 호출은 이유 묻기의 근거로 명령의 앞 1,000자와 출력의
끝 1,000자도 함께 남깁니다. 터미널의 그림 막대는 `/tmp/tool-timeline/<세션>` 아래에 파일로 만들고,
세션이 시작될 때 하루 동안 쓰이지 않은 폴더를 지웁니다.
